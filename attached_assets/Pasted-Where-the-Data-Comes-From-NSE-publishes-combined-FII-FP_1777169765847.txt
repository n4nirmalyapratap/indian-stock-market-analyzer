Where the Data Comes From
NSE publishes combined FII/FPI & DII trading data across NSE BSE, NSE and MSEI, compiled based on trades executed by institutional investors. The data is provisional and updated daily. There are 3 practical ways to fetch it in Python:

✅ Method 1: Direct NSE API (Free, No Key Needed — Recommended)
NSE has an internal JSON endpoint that Groww and others use. The trick is NSE requires a valid session cookie, so you must first hit the homepage to get one.
pythonimport requests
import pandas as pd

def get_nse_session():
    """NSE requires a browser-like session with cookies."""
    session = requests.Session()
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                      "AppleWebKit/537.36 (KHTML, like Gecko) "
                      "Chrome/120.0.0.0 Safari/537.36",
        "Accept-Language": "en-US,en;q=0.9",
        "Accept-Encoding": "gzip, deflate, br",
        "Referer": "https://www.nseindia.com/",
    }
    session.headers.update(headers)
    # This sets the necessary cookies
    session.get("https://www.nseindia.com", timeout=10)
    return session

def get_fii_dii_data():
    session = get_nse_session()
    
    # ✅ Equity FII/DII (like Image 1 — daily buy/sell)
    url = "https://www.nseindia.com/api/fiidiiTradeReact"
    response = session.get(url, timeout=10)
    data = response.json()
    df = pd.DataFrame(data)
    return df

def get_fii_dii_historical(start_date: str, end_date: str):
    """
    Dates in format: '24-03-2026'
    """
    session = get_nse_session()
    url = (
        f"https://www.nseindia.com/api/historical/fiidii"
        f"?startDate={start_date}&endDate={end_date}"
    )
    response = session.get(url, timeout=10)
    data = response.json()
    return pd.DataFrame(data.get("data", data))

# Usage
df_today = get_fii_dii_data()
print(df_today)

df_hist = get_fii_dii_historical("01-03-2026", "24-04-2026")
print(df_hist.head())

✅ Method 2: nsefin Library (Easiest)
nsefin is a lightweight Python package that wraps NSE India's endpoints and returns clean pandas DataFrames. It has a nse.get_fii_dii_activity() method designed specifically for market breadth and flows dashboards. PyPI
bashpip install nsefin
pythonimport nsefin

nse = nsefin.NSEClient()

# Daily FII/DII activity — returns a DataFrame
df = nse.get_fii_dii_activity()
print(df)

✅ Method 3: nsepython Library (More Features)
nsepython is a comprehensive Python library that provides easy access to publicly available NSE data, and has migrated all functions from older packages like NsepY and NSETools. PyPI
bashpip install nsepython
pythonfrom nsepython import fii_dii_data

# Returns FII/DII data as a DataFrame
df = fii_dii_data()
print(df)

⚠️ Common Pitfalls

403 Forbidden: You forgot to hit the NSE homepage first to get cookies → use the get_nse_session() function above
Rate limiting: Add time.sleep(1) between requests, and handle 429 errors with retry logic
NSE's public endpoints can change without notice — handle HTTP 301/403/429, add retry with backoff, and include a realistic User-Agent header PyPI
Data is only available after market hours (~6 PM IST) for the current day
